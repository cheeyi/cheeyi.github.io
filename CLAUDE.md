## Overview

Personal website and blog (cheeyi.me) built with Astro 5, deployed to GitHub Pages via GitHub Actions on every push to `main`. Migrated from Jekyll in November 2025. Zero client-side JS by default; TypeScript in strict mode.

## Commands

```sh
npm install        # install dependencies (Node 20+ required)
npm run dev        # dev server at http://localhost:4321
npm run build      # production build to ./dist (also type-checks content frontmatter)
npm run preview    # preview the production build
```

There are no tests or linters; `npm run build` is the verification step.

## Architecture

- **Content collection**: blog posts live in `src/content/blog/` as `.md` (or `.mdx` when embedding components like `<GithubRepoCard />`). The frontmatter schema is defined in `src/content.config.ts` (Zod): `title` required; `description`, `pubDate`, `updatedDate`, `heroImage`, `categories` ("tech" or "random") optional. Posts are rendered by `src/pages/blog/[...slug].astro` through the `src/layouts/BlogPost.astro` layout.
- **Pages**: `src/pages/` — homepage (`index.astro`), resume (`resume.astro`, data-driven from `src/data/skills.ts`), blog index, 404, and RSS feed (`rss.xml.js`). Sitemap is generated by the `@astrojs/sitemap` integration.
- **Site constants**: `SITE_TITLE` / `SITE_DESCRIPTION` in `src/consts.ts`; site URL and Shiki/MDX/icon config in `astro.config.mjs`.
- **Images**: place in `src/assets/` and reference with relative paths (`../../assets/foo.png`) so Astro/sharp optimizes them. `public/` is for files served verbatim.
- **Icons**: `astro-icon` with the `mdi` and `simple-icons` Iconify sets (see `src/data/skills.ts` for usage).

## Theming

All styling is in `src/styles/global.css` plus scoped `<style>` blocks in components. The site is themed through CSS custom properties:

- Light mode tokens in `:root`, dark mode in `[data-theme="dark"]`. To retheme, change only `--accent` and `--accent-hover` in both blocks — tinted backgrounds derive via `color-mix()`.
- Dark mode is toggled by a script in `src/components/Header.astro` that sets `data-theme` on `<html>` and persists to `localStorage`; `src/components/BaseHead.astro` contains the inline pre-paint script that applies the saved theme to avoid a flash.
- Any visual change must look good in **both light and dark mode** (verify dark mode explicitly), and design changes should be done on a branch first.
